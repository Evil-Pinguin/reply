# 💬 Reply

**Не чат. Настоящее первое свидание.**

Reply — интерактивный симулятор первого свидания: мобильная веб-платформа, где знакомство превращается в эмоциональный опыт. После взаимной симпатии чат не открывается сразу — сначала вы вместе планируете свидание (дата, время, локация, активности), ждёте встречи с обратным отсчётом, а в назначенный момент оказываетесь в живой виртуальной локации, где и начинается общение.

## Сценарий

```
Регистрация → Создание персонажа → Заполнение профиля → Свайпы (5 человек в день)
→ Match → Планирование (дата · время · локация · активности) → Ожидание с отсчётом
→ Свидание (живая сцена + чат) → Воспоминания → Дневник → Новые свидания
```

## Возможности

- **14 локаций** — кофейня, ресторан, парк, кинотеатр, галерея, набережная, пляж, японский сад, библиотека, игровое кафе, планетарий, домик в горах, яхта. У каждой — свой градиент неба, погодные частицы (дождь, листья, снег, звёзды, лепестки), плавающие объекты, случайные события и «сейчас играет».
- **Живая сцена свидания** — анимированные персонажи (машут, пьют, смеются, краснеют, думают), стол со свечами, официант приносит заказы, блюда появляются на столе.
- **Минималистичные аватары** — вместо эмодзи-лиц: сгенерированные плоские иллюстрации для персонажей и пользователя (12 вариантов).
- **Генеративный ИИ-собеседник** — ответы не выбираются из готовых фраз, а собираются на лету: анализ тем и тона сообщения, личные взгляды персонажа (у каждого свои), память разговора («ты раньше говорил(а) про…»), вопросы по словам пользователя, сочувствие, юмор, короткие «дописывания» как у живого человека. Партнёр задумывается, шутит, смущается, сам пишет первым, вспоминает прошлые свидания.
- **Активности** — карточки вопросов, викторина, камень-ножницы-бумага, совместное фото (canvas-кадр «POV»), цветы, музыка, закат, звёзды, утки…
- **Меню локаций** — заказ блюд с реакцией партнёра и появлением еды на столе.
- **Развитие отношений** — 5 шкал (доверие, комфорт, юмор, симпатия, романтика), настроение персонажа, дневник отношений, письма после свиданий.
- **Контент-машина** — автоматические шеринг-карточки свидания (canvas, скачивание PNG), «разбор вечера» (что было хорошо / забавно / какие темы зацепили).
- **Дофаминовые механики** — анимация мэтча, конфетти, достижения, серия свиданий 🔥, звуковые отклики (WebAudio), голосовые сообщения персонажей.
- **Reply Premium** — безлимитные свидания, эксклюзивные локации (планетарий, домик в горах, яхта), настолки, совместный просмотр, голосовые свидания.
- **Профиль как соцсеть** — MBTI, темперамент, язык любви, стиль общения, ценности, интересы, галерея, воспоминания.

## Запуск

Статический проект без сборки:

```bash
python3 -m http.server 8080
# или: npx serve .
```

Откройте `http://localhost:8080` в браузере (лучше в режиме мобильного устройства — DevTools → Device Mode).

## Структура

```
index.html          — оболочка приложения
css/styles.css      — дизайн-система (glassmorphism, анимации, сцены)
js/
  main.js           — точка входа
  data.js           — персонажи, локации, активности, реплики ИИ
  state.js          — состояние + localStorage
  audio.js          — звуковые отклики и амбиент (WebAudio)
  effects.js        — частицы (дождь, снег, листья, звёзды), конфетти
  scene.js          — сцена свидания с анимированными персонажами
  chat.js           — чат + «мозг» собеседника
  cards.js          — генерация шеринг-карточек и фото (canvas)
  ui.js             — экраны и роутинг
assets/
  characters/       — портреты персонажей
  voice/            — голосовые сообщения
```

## Демо-режим

Чтобы не ждать назначенного времени, на экране ожидания есть кнопка **«Начать сейчас (демо)»**.
